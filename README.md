# عبدبدب

موقع ثابت عربي باسم عبدبدب🙂 بتصميم مستوحى من صورة الشجرة المزهرة ومشغل موسيقي يفتح نتائج خالد عبد الرحمن على يوتيوب

## التشغيل المحلي

شغل أي خادم ملفات ثابت داخل مجلد المشروع

```bash
python3 -m http.server 3000
```

افتح الصفحة على المنفذ 3000

## الرفع على GitHub Pages

ارفع كل محتويات هذا المجلد إلى مستودع GitHub ثم اختر فرع main ومجلد الجذر من إعدادات Pages

الصورة موجودة داخل public/assets/tree.jpg

الموقع لا ينزل أي ملف صوتي ولا يستضيف الصوت ويستخدم يوتيوب عبر التضمين وروابط البحث
